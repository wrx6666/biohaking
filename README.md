# Biohacking Clinic Prototype

Static prototype for the "Dobry Doctor" preventive medicine and family health management landing page.

## Structure

- `index.html` - main page markup.
- `css/styles.css` - custom visual styles and animation CSS.
- `js/tailwind.config.js` - Tailwind CDN theme configuration.
- `js/main.js` - interactive format selector and form submit handler.
- `DESIGN.md` - design system notes.
- `code.html` - original single-file export kept for reference.
- `assets/` - place local images, icons, and media here.

## Local Preview

```bash
python -m http.server 5500
```

Open `http://127.0.0.1:5500/index.html`.
